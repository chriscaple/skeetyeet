# Code of Conduct

SkeetYeet adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be kind and patient, welcome newcomers, and assume good faith. Harassment, personal attacks and discriminatory language aren't tolerated anywhere in the project: issues, pull requests, discussions or any other project space.

## Reporting

If someone's behaviour is a problem, contact the maintainers privately through [Carmel Avenue Media](https://www.carmelavenuemedia.ca). Reports are handled confidentially. Maintainers may remove, edit or reject contributions, and may temporarily or permanently ban contributors, as described in the Covenant's enforcement guidelines.
