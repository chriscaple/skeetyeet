# Security policy

SkeetYeet handles Bluesky sign-in tokens and can delete content, so we take security reports seriously.

## Reporting a vulnerability

Please **don't** open a public issue. Report it privately through GitHub instead:
**[Report a vulnerability](https://github.com/chriscaple/skeetyeet/security/advisories/new)**.

Include what you found, how to reproduce it, and what an attacker could do with it. We'll acknowledge your report within a few days and keep you updated until it's fixed. We're happy to credit you in the release notes.

## In scope

- Leaks of tokens, app passwords or archived content
- Anything that deletes, unfollows or exports data without the user's confirmation, or beyond what they selected
- The OAuth flow and client metadata hosted on skeetyeet.app

## Supported versions

Until 1.0, only the latest release receives security fixes.
