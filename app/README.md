# SkeetYeet app

The Flutter app for iOS, macOS, Android and Windows. Bundle ID: `ca.carmelavenuemedia.skeetyeet`.

```sh
flutter pub get
flutter test
flutter run -d macos   # or ios, android, windows
```

App icons are generated from [`../brand`](../brand) with `dart run flutter_launcher_icons`.
See the [repository README](../README.md) and [SCOPE.md](../SCOPE.md) for more.
